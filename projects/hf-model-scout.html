HF Model Scout

A fast, no-frills way to find the right open model and build a shortlist you can share, without forty open browser tabs.

What it is

Search, filter and compare Hugging Face models.

HF Model Scout is a small static web app for exploring the Hugging Face Hub.

Search the hub, narrow results by task, language, license and popularity, then star the models you like into a shortlist and compare them side by side.

No frameworks, no build step and no API keys — just plain HTML, CSS and JavaScript talking directly to the public Hub API from your browser.

Features

What it does.

  • Instant search

    Debounced search backed by the Hub's model API — results as you type.

  • Useful filters

    Filter by task, language and license, with a minimum-downloads slider.

  • Sort what matters

    Order by downloads, likes or most recently updated.

  • Shortlist

    Star models into a shortlist that's remembered between visits.

  • Side-by-side compare

    Put up to three starred models next to each other to decide.

  • Share as Markdown

    Copy your shortlist as a Markdown table, ready for a doc or a PR.
